# Text Wireframe (ASCII Layout) - ระบบจัดการสินค้าคงคลัง (Lab 04)

เอกสารร่างโครงสร้างหน้าจอแบบ Text Wireframe (ASCII Layout) 3 หน้าจอ ออกแบบโดยคำนึงถึง Persona (สมชาย รักษาคลัง: พนักงานคลังทักษะเทคโนโลยี 2/5) พร้อมข้อกำหนดด้าน Usability และ Accessibility (WCAG 2.1 AA)

---

## 1. หน้าจอที่ 1: เข้าสู่ระบบ (Login Screen)

### ASCII Wireframe
```text
+-----------------------------------------------------------------------+
|  [LOGO] ระบบจัดการคลังสินค้าและสื่อดิจิทัล (Inventory System)            |
+-----------------------------------------------------------------------+
|                                                                       |
|                       +-----------------------------+                 |
|                       |        เข้าสู่ระบบ           |                 |
|                       +-----------------------------+                 |
|                                                                       |
|   ชื่อผู้ใช้งาน (Username) *                                          |
|   +---------------------------------------------------------------+   |
|   | somchai_wh                                                    |   |
|   +---------------------------------------------------------------+   |
|   [!] กรุณากรอกชื่อผู้ใช้งานเป็นตัวอักษรภาษาอังกฤษหรืออีเมล            |
|                                                                       |
|   รหัสผ่าน (Password) *                                               |
|   +---------------------------------------------------------+-----+   |
|   | ********                                                | [o] |   |
|   +---------------------------------------------------------+-----+   |
|   (กดไอคอนตา [o] เพื่อแสดง/ซ่อนรหัสผ่าน)                              |
|   [!] รหัสผ่านไม่ถูกต้อง (หากลืมรหัสผ่าน กรุณาติดต่อ Admin แผนกไอที)   |
|                                                                       |
|   [ ] จดจำการเข้าสู่ระบบบนเครื่องนี้                                  |
|                                                                       |
|   +---------------------------------------------------------------+   |
|   |                  [ ปุ่มเข้าสู่ระบบ (Primary) ]                 |   |
|   +---------------------------------------------------------------+   |
|                                                                       |
|   ความช่วยเหลือ: ติดต่อฝ่ายสนับสนุนโทร 044-xxx-xxx ต่อ 101             |
+-----------------------------------------------------------------------+
```

### คำอธิบายการออกแบบตามหลัก Usability & Accessibility
- **Persistent Visible Labels:** มี Label ชัดเจนเหนือทุก Input Field ไม่ใช้เฉพาะ Placeholder เพื่อป้องกันความสับสนสำหรับผู้ใช้ที่มีทักษะระดับ 2
- **Show/Hide Password Toggle:** เพิ่มปุ่มสลับการมองเห็นรหัสผ่าน เพื่อลดข้อผิดพลาดในการพิมพ์ผิด
- **Descriptive Error Message:** ข้อความแจ้งเตือนข้อผิดพลาดมีสัญลักษณ์ `[!]` ประกอบ และบอกแนวทางแก้ไขอย่างชัดเจน
- **Clear Action Button:** ปุ่มเข้าสู่ระบบมีขนาดใหญ่ กินพื้นที่เต็มความกว้าง (Full Width) โดดเด่น ชัดเจน

## 2. หน้าจอที่ 2: หน้าแรกและแดชบอร์ด (Dashboard Screen)

### ASCII Wireframe
```text
+-----------------------------------------------------------------------+
| [LOGO] ระบบคลังสินค้า  | หน้าหลัก | คลังสินค้า | รายงาน | [สมชาย (ผู้ใช้งาน)] [ออกจากระบบ] |
+-----------------------------------------------------------------------+
| แดชบอร์ดสรุปภาพรวมสินค้าคงคลัง                                          |
|                                                                       |
| +--------------------+ +--------------------+ +---------------------+ |
| | มูลค่าคลังรวม      | | สินค้าจับต้องได้   | | สินค้าดิจิทัล       | |
| | ฿ 1,245,000.00     | | 142 รายการ         | | 38 รายการ           | |
| +--------------------+ +--------------------+ +---------------------+ |
|                                                                       |
| [!] การแจ้งเตือน: มีสินค้า 3 รายการที่มีจำนวนต่ำกว่าเกณฑ์ขั้นต่ำ!       |
|                                                                       |
| +-------------------------------------------------------------------+ |
| | ตารางสินค้าสต็อกต่ำที่ต้องสั่งซื้อด่วน (Low Stock Alert)          | |
| +----------+------------------------+--------+-------+-------+------+ |
| | รหัส     | ชื่อสินค้า             | ชนิด   | คงเหลือ| เกณฑ์ | จัดการ| |
| +----------+------------------------+--------+-------+-------+------+ |
| | ELEC-001 | สายไฟทองแดง 2.5 sq.mm  | [กายภาพ]| 12 ม.  | 15 ม. | [สั่ง]| |
| | BRK-030  | เบรกเกอร์ 30A          | [กายภาพ]| 4 ชิ้น | 10 ชิ้น| [สั่ง]| |
| | TOOL-005 | คีมตัดสายไฟความแม่นยำ  | [กายภาพ]| 2 อัน  | 5 อัน | [สั่ง]| |
| +----------+------------------------+--------+-------+-------+------+ |
|                                                                       |
| แถบเมนูด่วน:                                                           |
| [+ เพิ่มสินค้าใหม่ (Primary Button)]   [v บันทึกจ่ายออก]   [ รายงานมูลค่า] |
+-----------------------------------------------------------------------+
```

### คำอธิบายการออกแบบตามหลัก Usability & Accessibility
- **Dual Product Classification:** แยกสถิติและประเภทสินค้าชัดเจน โดยมี Badge ระบุ `[กายภาพ]` (Physical) และ `[ดิจิทัล]` (Digital) อย่างโปร่งใส
- **Color + Icon Multi-modal Alert:** การแจ้งเตือนสต็อกต่ำมีกรอบเตือนและเครื่องหมายตกใจ `[!]` ชัดเจน ไม่พึ่งพาการใช้สีเหลือง/ส้มเพียงอย่างเดียว
- **High Visual Hierarchy:** แยกปุ่ม Primary Action `[+ เพิ่มสินค้าใหม่]` ชัดเจนด้วยสีเด่นและเครื่องหมายบวก

### คำอธิบายการออกแบบตามหลัก Usability & Accessibility
- **Conditional Form Fields based on Product Type:** เมื่อผู้ใช้สลับเป็น "สินค้าดิจิทัล" ฟิลด์จำนวนสต็อกและเกณฑ์สต็อกต่ำจะถูกซ่อน และแทนที่ด้วยช่อง "ลิงก์ไฟล์ดาวน์โหลด" ป้องกันไม่ให้พนักงานต้องใส่สต็อกมั่วซั่ว
- **Validation State with Solution Guidance:** ใต้ช่องราคาแสดงข้อผิดพลาด `[!] ราคาต้องมากกว่า 0 บาท` พร้อมระบุแนวทางแก้ไข
- **Distinct Primary & Secondary Buttons:** ปุ่มบันทึกวางไว้ขวาสุด เด่นชัด ใช้สี Primary (`#1E40AF`) ในขณะที่ปุ่มยกเลิกใช้สีรอง (Neutral/Secondary) ป้องกันการกดผิด
- **Success Feedback Banner:** แสดง Banner สีเขียว `[ V ]` ด้านบนสุด ยืนยันผลการบันทึกชัดเจน
