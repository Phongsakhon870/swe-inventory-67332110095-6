# UI Mockup Reference - Lab 04

ไฟล์ Mockup ออกแบบโดยใช้ draw.io (diagrams.net) ครบถ้วน 2 หน้าจอหลัก ได้แก่:
1. Dashboard Screen (แดชบอร์ดสรุปยอด, แยกสินค้ากายภาพและดิจิทัล, แจ้งเตือนสต็อกต่ำ)
2. Add Product Screen (ฟอร์มเพิ่มสินค้า, ปรับเปลี่ยนตามชนิดสินค้า Physical/Digital, แสดงสถานะบันทึกสำเร็จ)

ไฟล์ Draw.io ในโฟลเดอร์ assets:
inventory_mockups.drawio

(สามารถเปิดดูหรือแก้ไขไฟล์นี้ได้โดยตรงผ่านโปรแกรม draw.io หรือผ่านเว็บ https://app.diagrams.net โดยการเลือก Open Existing Diagram)
